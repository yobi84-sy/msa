# 구성도 아이콘 출처

구성도는 기존 단일 HTML 애니메이션에 내장된 SVG·PNG를 재사용합니다. SVG/PNG에 포함되어 외부 이미지 로딩 없이 표시됩니다. 서비스·프로젝트 이름은 각 소유자의 표기입니다.

| 구분 | 출처 |
| --- | --- |
| iam 등 | [원본](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip) |
| argo 등 | [원본](https://raw.githubusercontent.com/cncf/artwork/main/projects/argo/icon/color/argo-icon-color.svg) |
| prometheus 등 | [원본](https://raw.githubusercontent.com/cncf/artwork/main/projects/prometheus/icon/color/prometheus-icon-color.svg) |
| app 등 | [원본](https://raw.githubusercontent.com/cncf/artwork/main/projects/kubernetes/icon/color/kubernetes-icon-color.svg) |
| grafana 등 | [원본](https://raw.githubusercontent.com/grafana/grafana/main/public/img/grafana_icon.svg) |
| actions 등 | [원본](https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-24.svg) |

AWS 서비스와 Argo CD·Prometheus·Grafana·GitHub는 기존 브랜드 이미지 자산을 사용했습니다. Terraform·Actions·사용자·일부 앱 기호는 설명용 도식이며 공식 로고로 표기하지 않습니다. SQS 아이콘을 추가해 구현된 것처럼 표시하지 않습니다.
