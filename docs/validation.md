**기준일: 2026-10-19.** 소스에 구현된 내용, GitHub에서 조회한 실행 결과, 실습 중 확인한 동작을 구분합니다. 이 문서 작성 작업에서 AWS 리소스를 다시 설치하거나 부하를 발생시키지 않았습니다.

## 근거의 종류

| 구분 | 의미 |
| --- | --- |
| GitHub 실행 조회 | Actions의 해당 run이 completed/success였음을 API로 조회 |
| 실습 확인 기록 | 배포 당시 화면·메일·로그와 운영자의 확인에 근거 |
| 로컬 검사 | mock·임시 저장소·로컬 브라우저 등에서 수행. 실환경 재설치와 구분 |
| 구현 확인 | 현재 코드/설정에 존재. 실제 장애·최종 수신까지 검증했다는 뜻은 아님 |

## 소스에서 확인할 수 있는 검사

회원·상품·주문·API Gateway의 Docker 빌드는 `./gradlew test bootJar`를 실행합니다. 위 Actions 성공은 해당 커밋의 이미지 빌드 성공에 대한 근거입니다. 현재 문서 커밋에서 Java 테스트를 새로 수행한 것으로 기록하지 않습니다.

[주문 테스트](../msa/ordering/src/test/java/com/example/ordersystem/OrdersystemApplicationTests.java)는 요청 키 재전송, 마지막 재고 동시 주문, 같은 요청의 동시 실행, Outbox 삽입 실패 시 주문/재고 롤백을 다룹니다. [상품 테스트](../msa/product/src/test/java/com/example/ordersystem/OrdersystemApplicationTests.java)는 관리자 권한과 품절 공개 경로를 확인합니다. 테스트 환경의 성공은 MySQL 실환경 전체 동시성 시험과 동일하지 않습니다.

## 통합 실행 패키지의 로컬 검사

별도 통합 패키지 정리 시 한글·공백이 있는 다른 경로에서 33개 회귀 검사 그룹을 확인했습니다. 패치 순서·해시·승인 통신·기준본 복원·GUI 상태 등 로컬 검사 기록이며, 로그 원본은 로컬에 보관합니다.

이번 애니메이션은 파일 하나만 다른 폴더에 복사해 로드했습니다. 아이콘·입자·24개 장면·재생/정지·자동 전환·끝 정지·다시 재생·키보드·확대·상세 코드·반응형 화면을 확인했고 HTTP 요청 없이 실행했습니다.

## 미확인·추가 검증 범위

- 최신 통합 실행 패키지를 새 PC에서 최초 설치→모든 패치→삭제까지 실환경으로 다시 수행하는 전체 재검증
- SMS의 최종 단말 수신과 장애 후 재처리의 모든 경계 조건
- 모든 알람 규칙별 실제 장애 유발·복구 및 이메일 수신 시험
- HPA 5개 서비스와 노드 최대치까지의 지속 부하·복구 측정
- RDS Multi-AZ failover, SQS/DLQ, 원격 state 잠금: 현재 적용 완료 항목이 아님
- 로그인 유지 기간·토큰 저장 방식의 별도 보안 검토. 재접속 시 로그인 상태 유지 현상을 원인 확인 없이 해결 완료로 기록하지 않음

## 문서 이미지의 성격

`storefront-preview.png`, `admin-preview.png`는 현재 HTML/CSS/JS에 예시 API 응답을 연결한 **로컬 화면 재현**입니다. 실제 AWS API를 호출하거나 주문을 생성하지 않았습니다. `architecture.png`는 코드 기반 설명도, 애니메이션은 오프라인 시뮬레이션입니다. 이미지 자체를 실환경 성공 증거로 대신하지 않습니다.
